Seguridad

Reportar un problema

Si detectas un posible problema de seguridad en WMS360, envía un reporte describiendo el comportamiento observado.

Incluye únicamente información necesaria para investigar el incidente.

No envíes contraseñas, tokens, API keys, App Secrets, códigos de recuperación ni otras credenciales sensibles por correo.
